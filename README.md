## ✨ Features

- **Dynamic Question Rendering:** Displays multiple-choice questions loaded dynamically via JavaScript.
- **Instant Visual Feedback:** Highlights the correct answer in green and incorrect selections in red upon clicking.
- **Real-Time Progress & Score Tracking:** Displays current question index, dynamic progress bar, and active score updates.
- **Score-Based Feedback Screen:** Generates tailored evaluation messages based on final score percentages.
- **Restart Capability:** Smooth transition back to the start without page reloads.
- **Fully Responsive Design:** Optimized for both mobile devices and desktop screens.

---

## 🛠️ Built With

- **HTML5:** Semantic page layout and structured screens (Start, Quiz, Result).
- **CSS3:** Custom UI design, responsive flexbox/grid layout, transitions, and progress bar animations.
- **JavaScript (ES6):** DOM manipulation, state handling, event listeners, and dynamic score calculation.
- **GitHub Pages:** Deployment and live hosting.
